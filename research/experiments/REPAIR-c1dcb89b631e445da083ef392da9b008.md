# REPAIR-c1dcb89b631e445da083ef392da9b008: bounded Except fallback

## Scope and result

Reproduced the bounded fallback from public PR #40 head
`360d6bdf93eeb541cd8b80b4426a93b68618d0be` on current base
`3a7c71e41ba1a29df363e8847fbe5a01e3a96bf8`. It visits local declarations in
context order, tries an `Except` candidate only when reached, splits exactly
one candidate, and requires every resulting branch to close. Each attempt saves
and restores tactic state on failure. The fallback is after Option branching
and before ListCommand branching.

`ResultFlow.lean` retains the original subtraction theorem and the equal-counter
theorem, with their original assumptions. It also checks an unchanged failure
state, a false proposition under `fail_if_success`, an irrelevant first Except
candidate followed by a useful candidate, rejection of a partially closing
split, and the one-split bound. Successful results update both counters by the
same amount. No theorem statement, definition, assumption, or bound was weakened.
