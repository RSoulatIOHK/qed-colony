## Scope and acceptance

The target bounds the length of `List.filter` for any element type, predicate, and input list. It has no additional assumptions or fuel bound. The nearby control falsely claims the filtered output is always one element longer. Both statements were attempted directly with exactly `by colony`.

```lean
universe u

theorem filter_length_bound {α : Type u} (p : α → Bool) (xs : List α) :
    (xs.filter p).length ≤ xs.length := by colony

theorem false_filter_length_bound {α : Type u} (p : α → Bool) (xs : List α) :
    (xs.filter p).length = xs.length + 1 := by colony
```
